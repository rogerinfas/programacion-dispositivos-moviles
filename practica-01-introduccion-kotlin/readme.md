# ACTIVIDAD. Práctica 1. Introducción a Kotlin.
**Comprobación de pasos requeridos por la tarea

Este directorio demuestra la finalización de la **Práctica 1**. A continuación se detalla el cumplimiento de cada paso de la actividad:

*  **Paso 1 y 2:** Entorno de desarrollo configurado correctamente con IntelliJ IDEA y herramientas de Kotlin.
*  **Paso 3:** Se incluyó el uso de la lectura por teclado (`readln().toIntOrNull()`, `readln().toDoubleOrNull()`) para prevención de errores, así como el uso de datos aleatorios con `Random.nextInt()`.
*  **Paso 4:** Se resolvieron los 4 problemas requeridos en sus archivos individuales:
  * `Ejercicio1.kt`: Lógica de evaluación de empleados.
  * `Ejercicio2.kt`: Juego de Piedra, Papel o Tijeras vs CPU.
  * `Ejercicio3.kt`: Calculadora base con menú recursivo.
  * `Ejercicio4.kt`: Juego matemático de adivinar el número secreto.
*  **Paso 5:** Todos los problemas fueron subidos a este repositorio público de GitHub, dentro del directorio de la práctica actual.
*  **Paso 6:** La autorúbrica de la actividad fue contestada meticulosamente y se encuentra en el archivo [`autorubrica.md`](./autorubrica.md).
*  **Paso 7:** Archivos listos para enviar la liga del repositorio.

## Ejecución de Archivos Generados
Si deseas compilar manualmente alguno de estos ejercicios desde la terminal, puedes utilizar los siguientes comandos de ejemplo (usando Ejercicio1):

```bash
kotlinc Ejercicio1.kt -include-runtime -d Ejercicio1.jar
java -jar Ejercicio1.jar
```
